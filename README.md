# TaskFlow Workspace

A full-stack task management web application developed with Flask, SQLAlchemy, and Bootstrap 5, deployed on Render.

## 🚀 Live Demo
- **Web App:** [TaskFlow on Render](https://flask-todo-app-3-tcun.onrender.com)

---

## 📌 Features
- **Full CRUD Support:** Create, view, update, and remove tasks dynamically.
- **Priority Tracking:** Organize tasks using priority levels (High, Medium, Low) highlighted with visual status badges.
- **Application Context Initialization:** Automatic database schema creation on server boot using Flask-SQLAlchemy.
- **Responsive UI:** Modern card-based dashboard layout built with Bootstrap 5.

---

## 🛠️ Tech Stack
- **Backend:** Python 3, Flask
- **ORM & Database:** Flask-SQLAlchemy, SQLite
- **Production Server:** Gunicorn (WSGI)
- **Frontend:** HTML5, Jinja2, Bootstrap 5
- **Hosting / Deployment:** Render Cloud Platform
